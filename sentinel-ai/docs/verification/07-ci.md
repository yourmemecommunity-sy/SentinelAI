## Defect found and fixed: GitHub would never have run the workflow

The git repository root is the folder **above** `sentinel-ai/`, but the workflow lived at `sentinel-ai/.github/workflows/ci.yml`.
GitHub Actions only reads `.github/workflows/` at the repository root, so **a push would have run no CI at all**. Earlier
`act` runs hid this because they snapshotted `sentinel-ai/` as if it were the root.

Fix (decision D7): the workflow moved to `<repo root>/.github/workflows/ci.yml`, with `defaults.run.working-directory: sentinel-ai`,
`sentinel-ai/`-prefixed step directories and artifact paths, `pnpm/action-setup` pointed at `sentinel-ai/package.json`, and
gitleaks scanning `$GITHUB_WORKSPACE` (the real git root) with `sentinel-ai/.gitleaks.toml`. `sentinel-ai/.github/workflows/`
keeps its `.gitkeep` (the structure validator requires the folder).

## Second defect found and fixed: the OpenAPI contract tests never ran in CI

`tests/security/test_api_contract.py` starts with `pytest.importorskip("yaml")`, and the CI job did not install PyYAML, so
its 5 contract tests were **silently skipped** in CI (they only ever ran on the dev machine). The job now installs
`pyyaml>=6,<7` first and runs pytest with `-rs`, so any future skip is printed with its reason. Re-run under `act`:
`15 passed in 0.77s`, 0 skipped, job succeeded; actionlint still clean.
